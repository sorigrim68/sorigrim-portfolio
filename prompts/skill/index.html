프롬프트 구조 패턴

991개 프롬프트에서 발견된 6가지 핵심 구조입니다. 상위 크리에이터들은 대부분 CAPS 섹션 헤더나 타임라인 분할 구조를 사용합니다.

🥇 가장 많음 · 170개

씬 직접 묘사형

장면을 직접 서술하는 가장 자연스러운 방식. "A lone warrior stands at the edge of..." 처럼 시작. 짧고 직관적이지만 AI 해석 여지가 큼.

평균 450자 · 간결한 컨셉에 적합
🥈 138개

스타일 + 시간 선언형

첫 줄에 STYLE: / DURATION: 을 선언하고 씬을 이어가는 방식. AI가 톤을 즉시 파악해 일관성이 높아짐.

평균 699자 · 상업 광고·패션에 최적
🥉 92개

패널 / 스토리보드형

PANEL 01, PANEL 02 또는 Shot 1, Shot 2 형태로 컷을 분리. 복잡한 씬 흐름을 정밀하게 제어 가능.

평균 810자 · 멀티씬·스토리 영상에 최적
⏱ 52개

타임코드 분할형

[0-3s], [3-7s], [7-11s] 처럼 초 단위로 씬을 나눔. 가장 정밀하게 영상 흐름을 제어할 수 있는 고급 방식.

평균 900자 이상 · 액션·SF에 최적
🔠 59개

CAPS 섹션 헤더형

CHARACTER:, ARENA:, TECHNICAL:, CAMERA: 등 대문자 헤더로 정보를 분류. AI가 각 요소를 독립적으로 처리.

평균 750자 · 캐릭터 중심 영상에 최적
🖼 46개

이미지 레퍼런스 + 지시형

"Use @image1 as reference for..." 형태로 이미지를 특정 역할에 결합. 캐릭터 일관성이나 스타일 재현에 사용.

평균 600자 · 이미지-투-비디오에 필수
02

최적 길이와 밀도

길수록 무조건 좋은 것이 아닙니다. 핵심 정보의 밀도가 중요합니다. 분석 결과 200~900자 범위가 최적이었습니다.

길이비중특징적합한 용도
< 200자2.5%매우 짧음. AI 창의성에 의존실험적 컨셉 테스트
200~400자25%핵심만 담음. 간결하고 효과적단순 씬, 자연/풍경
400~700자30%⭐ 최적 범위. 스타일+씬+카메라 포함 가능대부분의 영상 유형
700~1000자25%상세 묘사. 캐릭터·의상·씬 분리액션, 캐릭터 중심
1000자+17%타임라인/패널 구조 필수. 복잡한 스토리광고, 멀티씬 영상

✓ 해야 할 것

  • 스타일을 먼저, 씬을 나중에
  • 카메라 무브먼트는 구체적으로
  • 조명 조건을 항상 명시
  • 영상 길이(duration)를 적어라
  • 감정·분위기를 단어로 지정

✗ 하지 말 것

  • 모순된 스타일 혼용 (realistic + cartoon)
  • 너무 많은 씬을 15초에 넣기
  • 추상적인 단어만 나열
  • 카메라 무브 없이 씬만 묘사
  • 텍스트/자막 지시 없이 넣기 기대
